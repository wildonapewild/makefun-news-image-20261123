# THE DAY IN DETAIL — Monday 23 November 2026

One page, one day: the whole of Monday 23 November 2026 set out as a
classic front page — a big gold lead, twelve more cards, a dotted world
map with numbered pins, the day in numbers, and a date check that keeps
older stories out.

## Run it

    python3 main.py

That copies the finished `entry.png` into the folder named by
`MAKEFUN_OUTPUT_DIR` (or `out` when the variable is not set).

`compose.py` is the drawing board that produced the page, and
`test_entry.py` checks the finished file's size and dimensions.
